# 听见从前

用说话共建的个人化怀旧视听场景系统。老人坐在大屏幕前，不碰任何设备，只需要说话：系统像一位温和的晚辈陪他/她聊小时候住的地方，并**根据讲述实时生成和修改**一个 360° 的“老家”场景——画面是统一风格的水彩/老连环画插画，场景里的物件会发出声音，声音的方向和远近随视角变化。会谈结束后，每位老人得到一个可以在手机上离线打开的“老家漫游”网页，里面是他/她的场景和自己讲的故事。

系统同时支持一个小型研究：比较“只听 / 通用场景 / 个人共建场景”三种条件下老人讲述的时长和细节。

> 本项目是“怀旧活动”工具，不是医疗器械，不做任何“治疗”或“诊断”。

实现计划见 [docs/PLAN.md](docs/PLAN.md)。

## 快速开始（演示模式，无需任何 Key）

需要：Python 3.11+、Node.js 18+、ffmpeg。以下命令都在仓库根目录执行。

```bash
pip install -r backend/requirements.txt
```

```bash
python scripts/download_models.py
```

```bash
cd frontend && npm install && npm run build
```

```bash
cd backend && uvicorn app.main:app --host 127.0.0.1 --port 8000
```

打开 <http://127.0.0.1:8000/setup.html> → 新建参与者（只填编号，如 `P001`）→ 勾选知情同意 → “开始会谈”。会谈页打开后点一下屏幕开始，按 **S** 键呼出工作人员面板，在输入框里打字模拟老人说话，例如：

- “我小时候住在上海的弄堂里，石库门房子，六十年代。巷口有个卖馄饨的，敲着梆子。”
- “那个卖馄饨的老头腿脚不好，我们都叫他阿福伯。”（故事归档）
- “卖馄饨的不在这儿，在巷口那头。”（修改）→ “不对”（撤销）
- “下雨了，傍晚的时候。”“太吵了。”“今天就到这儿吧。”

没有配置百炼 API Key 时系统自动进入**演示模式**：用本地规则模拟语言理解，用程序绘制的占位全景和物件，陪聊者的声音用浏览器自带的中文语音。演示模式只用来熟悉流程和调试；真实会谈请配置云端服务。

## 需要哪些 API Key

| 服务 | 用途 | 是否必须 | 去哪里申请 |
|---|---|---|---|
| **阿里云百炼 DashScope** | 大语言模型（陪聊、理解、修改指令、故事归档、细节抽取）、实时语音识别、语音合成、通义万相图像生成、文本向量 | **必须**（真实会谈） | <https://bailian.console.aliyun.com/> → API-KEY 管理。一个 Key 覆盖全部百炼服务。 |
| Blockade Labs Skybox | 原生等距柱状投影全景 + 深度图（比万相的全景几何更准确） | 可选 | <https://skybox.blockadelabs.com/>（API 需付费订阅） |
| Freesound | 检索下载 CC0 / CC-BY 声音素材 | 可选（推荐） | <https://freesound.org/apiv2/apply/> |
| ElevenLabs | 网上找不到的声音用文生音效生成 | 可选 | <https://elevenlabs.io/> |
| Meshy | 图生 3D（物件从插画升级为 GLB 模型） | 可选，默认关闭 | <https://www.meshy.ai/> |

不需要 Key 的部分：深度估计在本地运行（Depth Anything V2 Small，ONNX）；Wikimedia Commons 与 Openverse 声音检索无需 Key。

**模型选择（2026 年 10 月查阅百炼官方文档）**

| 用途 | 默认模型 | 说明 |
|---|---|---|
| 陪聊、修改指令、讲述抽取、细节抽取 | `qwen3.7-plus` | 支持 JSON Schema 严格模式的结构化输出 |
| 话语分类、故事锚点、检索词 | `qwen3.8-flash` | 更快更便宜 |
| 实时语音识别 | `fun-asr-realtime` | 支持方言与热词；也可改用 `paraformer-realtime-v2`（协议相同） |
| 语音合成 | `cosyvoice-v3-flash`，音色 `longanrou_v3`（温和知心女声），语速 0.85 | 备选音色：`longyan_v3`（温暖成熟女声）、`longanyun_v3`（温和男声） |
| 全景图 / 物件插画 | `wan2.6-t2i` | 万相不输出透明背景，也不保证严格的球面投影，所以抠图和全景后处理在本地完成 |
| 文本向量 | `qwen3.7-text-embedding-flash` | 用于声音检索 |

模型名都写在 `.env` 里，百炼更新模型后直接改名字即可。结构化输出调用会先尝试 `json_schema` 严格模式，模型不支持时自动退回 `json_object` 模式，所有输出都经 Pydantic 校验、失败带错误信息自动重试。

| `DATA_DIR` | `data/` | 参与者数据目录（已加入 .gitignore） |

## 一场会谈怎么进行

1. 工作人员在设置页选择参与者、实验条件和时长，点“开始会谈”，在大屏幕上点一下开始（之后不需要再碰）。
2. 陪聊者问好，然后问老人小时候住在哪儿。老人说话时系统不打断，**停顿 4 秒以上**才回应。
3. **个人共建条件**：系统边聊边从讲述中抽取地域、年代、样子和物件。了解到足够信息后生成第一张全景图（30–60 秒），期间继续聊天、陆续加入物件和声音；全景图出来后从纸色淡入，陪聊者请老人看看、听听，说说哪里不像。
4. 老人可以随时说：
   - 修改：“卖馄饨的不在这儿，在巷口那头”“我们家没养鸡”“那天在下雨”“冬天下雪，房顶都白了”（重新画）
   - 导航：“往左边看看”“看看巷口”“去井边看看”（没有这个地方时会去画一个，画好了自动过去）
   - 撤销：“不对”“改回去”
   - 控制：“太吵了”“停一下”（0.4 秒内全部安静）、“可以了”（恢复）、“今天就到这儿”
5. 高置信度的修改直接执行，改动的物件轻轻高亮；没把握时陪聊者用一句话确认（“是说卖馄饨的应该在更远的巷口吗？”），老人说“对”再执行。
6. 老人讲的回忆会被截取录音、挂到场景中相关的物件或地点上（温和的光点）。
7. 老人说“今天就到这儿”、达到设定时长、或明显疲惫（陪聊者会先问一句）时，陪聊者温和道别，用一首欢快的老歌收尾。会后自动生成报告。

画面上不显示任何按钮和菜单。工作人员面板按 **S** 键（或连点左上角三次）呼出，可以看识别文字、调音量上限、手动安静/结束。

## 添加自己的素材

所有素材都登记在 `assets/manifest.json`（自动生成可读的 [`assets/REFERENCES.md`](assets/REFERENCES.md)），每个素材都有来源、授权、署名、版权状态、是否敏感和审核状态。

### 在线检索下载声音

```bash
python scripts/fetch_sounds.py
```

- 按 `config/catalog.yaml` 的声音词表（中英文关键词）检索：Wikimedia Commons、Openverse（无需 Key），配置了 `FREESOUND_API_KEY` 时同时检索 Freesound；只下载 CC0 / 公有领域 / CC-BY / CC-BY-SA，非商业（NC）、禁止演绎（ND）和授权不明确的一律不下载。
- 下载后自动转成 mp3、响度归一化、登记来源和署名，状态为“待审核”。
- `--dry-run` 只列候选；`--keys 木梆子 自行车铃` 只处理部分词条；`--query 木梆子 "wooden fish percussion"` 追加检索词。
- 配置了 `ELEVENLABS_API_KEY` 时，网上找不到的词条用文生音效生成，同样登记。
- 会谈中老人提到没有素材的声音，会记入场景的 `unresolved`，并在后台自动尝试在线检索/生成。

在设置页“素材审核”里试听：选“通过”的优先使用，选“不用”的永远不会进入场景。

### 程序合成的基础音效

仓库里已有 20 个程序合成的基础音效（木梆子、自行车铃、雨打瓦片、风声、蟋蟀、蝉鸣、挂钟、收音机调台、汽笛等，物理建模/滤波噪声生成，`scripts/synth_sounds.py`），保证没有网络素材时也能用。它们是占位素材，有了真实录音后建议在“素材审核”里把它们标为“不用”。

### 自己修复的老录音、冲激响应、自己的录音

把文件放进对应目录，然后运行：

```bash
python scripts/register_local_assets.py
```

| 目录 | 内容 |
|---|---|
| `assets/sounds/my_restorations/` | 自己修复的老歌、戏曲录音 |
| `assets/sounds/own/` | 自己录制的声音 |
| `assets/irs/` | 设备冲激响应，文件名以 `old_radio` / `loudspeaker_horn` / `gramophone` 开头 |

第一次运行会在每个音频旁边生成同名的 `.yaml` 说明模板，填写名称、标签、年代、原始来源、**版权状态**（`public_domain` / `cc` / `copyrighted` / `unknown`）、使用范围、署名、效果链（如 `gramophone`）后再运行一次。标记 `closing_song: true` 的欢快老歌会用作会谈收尾。版权状态不是 `public_domain` / `cc` 的录音只在本地会谈中播放，**不会被导出到“老家漫游”网页**。

### 图片

全景图和物件插画在使用时按需生成，自动缓存并登记（AI 生成 + 服务 + 提示词）。同一风格下同一种物件（如“馄饨担子”）只生成一次，之后所有参与者复用。个人化的全景图存放在 `data/scenes/`（不提交），通用场景的全景图按地域缓存在 `assets/images/panoramas/`。

按 2026 年 10 月百炼官方标价（原价，未计优惠；以控制台为准）粗略估算一场 30 分钟的会谈：

| 项目 | 用量估计 | 单价 | 费用 |
|---|---|---|---|
| 实时语音识别 `fun-asr-realtime` | 麦克风全程 30 分钟 = 1800 秒 | 0.00033 元/秒 | ≈ 0.6 元 |

| 图像生成 `wan2.6-t2i` | 第一次会谈约 2–3 张全景 + 8–12 张物件；之后的会谈主要是修改和重绘 | 按张计费（请查看控制台标价，约 0.2 元/张量级） | 第一次 ≈ 2–3 元，之后 ≈ 0.5–1 元 |
| 文本向量 | 很少 | 0.0005 元/千 tokens | 可忽略 |
| **合计** | | | **第一次约 4–6 元，之后每次约 2–3 元** |

Skybox、Freesound、ElevenLabs、Meshy 按各自的订阅/计费。系统会统计调用量（设置页状态接口 `/api/status` 的 `usage` 字段，以及每场会谈的事件日志）。

## 研究数据与报告

**实验条件**

| 条件 | 画面 | 声音 | 修改 |
|---|---|---|---|
| `audio_only` 只听 | 一张模糊的暖色背景 | 该地域的通用声音场景 | 关闭 |
| `generic` 通用场景 | 该地域的通用全景和物件（按地域缓存，所有参与者共用） | 通用 | 关闭 |
| `personal` 个人共建 | 根据老人讲述逐步生成 | 个人化 | 开启 |

三种条件下陪聊者、故事归档和数据记录完全相同，只有画面和修改功能不同。

**事件日志**（SQLite `data/app.sqlite3` 的 `events` 表）：每句话（识别结果与时间戳）、每次分类结果、每条修改指令及置信度、是否执行和原因、确认与撤销、每次点位切换、每个故事、每次陪聊者发言、安静/插话、外部服务失败等，全部带时间戳。场景的每个版本和实体级差异保存在 `scene_versions` 表。

**会后自动分析**（会谈结束后自动运行，也可在设置页点“重新分析”）：

- 讲述总时长、段数、主动开口次数、字数、平均每段时长（定义见 `backend/app/research/analysis.py` 文件头）；
- 具体细节：人名、地名、时间、感官描述（声音/气味/颜色/温度/味道/触感）、事件，分别计数。**每一条都保留原话片段，存为 `details.csv`，请人工核对后再用于统计**；
- 修改次数与类型分布、讲述生成的元素数、确认/撤销次数、点位切换次数、故事数量。

报告位置：`data/reports/<会谈>/report.html`、`metrics.csv`、`details.csv`、`turns.json`。跨会谈/跨条件对比：设置页“跨条件对比报告”（HTML，平均值 ± 标准差，按参与者分列），可下载 CSV 导入 SPSS / R / Excel。

## 隐私与伦理

- 参与者只用编号，不存真名；设置页拒绝中文姓名作为编号。
- 录音、文字、场景版本和事件日志只保存在本地 `data/`（已加入 .gitignore）。设置页可以导出（zip）或**永久删除**一位参与者的全部数据。
- 调用云端服务时只发送必要的音频流和文字（老人的话、陪聊的话、场景摘要），不发送参与者编号或任何身份信息；请求头关闭了百炼的数据审查留存选项（`X-DashScope-DataInspection: disable`）。
- **不生成、不合成任何真实人物的面孔或声音**：物件和全景提示词强制人物只用远景/背影的风格化通用形象；陪聊者使用通用音色；人声素材只用通用的叫卖、招呼、广播。
- `sensitive` 素材（防空警报、批斗、口号等）永远不会被自动加入场景；检索和在线下载都会过滤敏感关键词。
- 陪聊者的提示词禁止问“您还记得吗”、禁止纠正老人、不主动提及战争/饥荒/政治运动/亲人去世等话题；输出还有一道过滤，去掉“还记得吗/记不记得”的问法。
- 主输出有限幅器和音量上限；老人说“停一下 / 太吵了 / 安静”时 0.4 秒内全部安静。
- 外部服务失败时重试、使用缓存、保持当前画面；错误只写进日志和工作人员面板，老人面前绝不出现报错或空白。
- 界面与文档使用“怀旧活动”“回忆”，不使用“治疗”“诊断”。

## 已知限制与后续工作

- **万相全景的几何**：万相按 2:1 生成并经后处理，左右接缝和两极已处理，但不保证严格的球面投影（地平线可能略有起伏）。物件放置以地面几何和深度上限为准，对此不敏感。需要更准确的全景时改用 Skybox。
- **声音素材**：开发环境（云端容器）访问 Wikimedia Commons 时被限流，所以仓库里目前只有程序合成的占位音效。请在自己的电脑上运行 `python scripts/fetch_sounds.py`（建议配置 Freesound Key），并在设置页试听审核。叫卖声、鸡鸭狗叫、人声、戏曲等无法合成的声音需要从网上获取或自己录制。
- **CLAP 声音内容匹配**：检索已融合标签、同义词、拼音和文本向量；音频-文本模型（CLAP）匹配尚未接入，`backend/app/assets/retrieval.py` 的 `rank()` 是接入点。
- **回声**：依赖浏览器的回声消除，并在陪聊者说话期间提高检测门限、过滤与陪聊原话高度重合的识别结果。外放音量较大时，建议使用指向性麦克风。
- **方言**：`fun-asr-realtime` 支持多种方言；口音很重时可以在百炼控制台为常用词（地名、小贩称呼）建立热词表，把 ID 填进 `.env` 的 `ASR_VOCABULARY_ID`。
- **云端服务未在开发环境实测**：所有接口按 2026 年 10 月的官方文档实现，并有完整的降级路径；第一次配置 Key 后，请先在设置页开一场测试会谈，确认识别、合成和图像生成都正常。
